# NewGig - Professional Website

A modern, professional website built with Next.js, React, and Tailwind CSS.

## 🚀 Features

- **Responsive Design**: Fully responsive on all devices
- **Modern UI**: Beautiful, professional design with smooth animations
- **Multiple Pages**: Home, Services, Portfolio, Testimonials, Pricing
- **SEO Optimized**: Meta tags and structured content
- **Performance**: Fast loading and optimized for Web Core Vitals
- **Accessibility**: Built with accessibility in mind

## 📋 Sections Included

1. **Header/Navigation**: Fixed header with mobile menu
2. **Hero Section**: Eye-catching hero with CTA buttons
3. **Services**: 6 featured services with icons
4. **Features**: Why choose us section with benefits
5. **Portfolio**: Project showcase grid
6. **Testimonials**: Client testimonials with ratings
7. **Pricing**: Three-tier pricing plans
8. **Call to Action**: Final conversion section
9. **Footer**: Complete footer with links and social media

## 🛠️ Tech Stack

- **Next.js 14**: React framework
- **TypeScript**: Type safety
- **Tailwind CSS**: Styling
- **React Icons**: Icon library
- **Framer Motion**: Animations

## 📦 Installation

```bash
npm install
```

## 🚀 Running the Project

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔨 Building for Production

```bash
npm run build
npm run start
```
